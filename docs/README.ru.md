# Документация проекта

[English index](README.md)

Anonymus Bot передаёт текст, фотографии и голосовые сообщения между
участниками Telegram-сессии. Оператор управляет сессиями через веб-панель.
Оператору доступно содержимое переписки. Telegram и хостинг могут хранить
собственные метаданные.
